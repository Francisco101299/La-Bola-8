# 🎱 La Bola 8

**Deja que el destino decida por vos**

Una app divertida que te ayuda a tomar decisiones cuando no sabés qué hacer, qué comer, o quién paga la cuenta.

## 🎯 ¿Qué hace?

- 🍕 Decide qué comer
- 🎬 Decide qué hacer
- 💰 Decide quién paga
- 🎥 Decide qué película ver
- 🏃 Te da excusas creativas
- 💕 Te dice si te quieren (o no 😅)

## 🚀 Cómo usar

1. Elegí una categoría
2. Tocá la bola para agitarla
3. ¡Dejá que el destino decida!

## 📱 Instalación

Esta es una Progressive Web App (PWA). Podés:
- Abrirla desde el navegador
- Añadir a pantalla de inicio en tu celular
- Compartir el link con amigos

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript vanilla
